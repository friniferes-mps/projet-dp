# THE EMOTION GAME — V13 ILLUSTRATED EDITION

Reprise du code fonctionnel V12 avec **14 illustrations locales** découpées du mockup fourni, pour rapprocher visuellement la projection de la maquette.

## Installation
`npm start` puis ouvrir `http://localhost:3000`. Régie : créer session ; projection : bouton « Ouvrir le grand écran ».

## Nouveautés
- Scène d’ouverture illustrée façon plateau télévisé
- Illustrations stress, émotions, cerveau, capsule, missions, corrections, outils, tribunal, podium et remerciements
- Aperçu graphique dans la régie
- Images WEBP embarquées : pas besoin d’internet pour les illustrations
- Logique serveur et vote de la V12 conservée

## Limites
Les illustrations sont des **images statiques intégrées**, pas des personnages 3D animés. Les textes figurant à l’intérieur des illustrations proviennent du mockup et peuvent différer des textes dynamiques du jeu. Les commandes et les textes de jeu sont de vrais éléments HTML indépendants. Tester Safari, son, réseau local, et projection avant le jour J.
