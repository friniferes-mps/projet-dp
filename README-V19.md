# THE EMOTION GAME — V19

Améliorations réellement apportées au code :
- Suppression de la vignette de classement extraite du storyboard et remplacement par un trophée typographique net.
- Classement sans scores chiffrés projetés ; ordre basé sur les scores internes.
- Mode projecteur immersif : en-tête et pied de page masqués, marges adaptées, typographie et contrastes renforcés.
- Illustrations affichées en entier (object-fit: contain), sans agrandissement artificiel de leur résolution.
- Checklist technique privée dans la régie (projection, son, réseau, vote).
- Écran participant en attente : ne divulgue plus le score de l'équipe.
- Accessibilité : focus clavier visible, préférence de mouvement réduit.

## Démarrage
`npm start` puis http://localhost:3000.

Limites : les illustrations V18 sont conservées, certaines sont des découpes du storyboard et leur définition native n'augmente pas. Test de rendu Safari et vote multi-appareils à effectuer sur place.
